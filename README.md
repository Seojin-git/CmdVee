윈도우의 `Win + V` 기능에서 영감을 받아 제작한 가볍고 빠른 **macOS 네이티브 메뉴바 클립보드 매니저**입니다. **Swift**, **SwiftUI**, **AppKit** 기반으로 지연 없는 키보드 탐색과 쾌적한 백그라운드 동작을 지원합니다.

## 주요 기능

- **다양한 데이터 형식 지원:** 복사한 **텍스트**, **이미지**(스크린샷, 웹 이미지 등), Finder의 **파일 및 폴더 경로**를 자동으로 감지해 저장합니다.
- **즉시 붙여넣기 (`Option + V`):** 전역 단축키로 상단 메뉴바 팝업을 즉시 호출합니다. 방향키(`↑`/`↓`)로 이동 후 `Enter`(또는 마우스 클릭)를 누르면 해당 항목을 클립보드 1순위로 복원하고 현재 작업 중인 창에 바로 붙여넣습니다.
- **스마트 보관 및 고정(Pin):**
  - 최대 보관 개수를 **10개 단위로 10~50개까지** 자유롭게 설정할 수 있습니다.
  - 자주 사용하는 항목을 **고정(Pin)**해 목록 최상단에 유지하고 자동 삭제 대상에서 제외할 수 있습니다.
  - 개별 항목 삭제 및 **전체 지우기** 기능을 지원합니다.
- **보안 및 사용자 제어:**
  - **일시 정지(Pause):** 메뉴바 팝업 상단 토글로 클립보드 기록을 언제든 일시 중지할 수 있습니다.
  - **제외 앱 설정:** 비밀번호 관리 앱 등 민감한 앱에서 복사한 내용은 기록하지 않도록 예외 처리할 수 있습니다.
  - **재부팅 후 유지 옵션:** 맥 재시작 후에도 히스토리를 유지할지, 앱 종료 시 초기화할지 사용자가 직접 선택할 수 있습니다.

## 단축키

| 단축키 | 동작 |
| :--- | :--- |
| `Cmd + C` | 기본 복사 (백그라운드에서 히스토리에 자동 저장) |
| `Option + V` | 클립보드 히스토리 팝업 열기 / 닫기 |
| `↑` / `↓` | 히스토리 목록 위/아래 탐색 |
| `Enter` | 선택한 항목을 클립보드 1순위로 덮어쓰고 현재 창에 즉시 붙여넣기 |
| `Esc` | 팝업 닫기 |
